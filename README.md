# 📇 Contact Manager

**Contact Manager** — это консольное приложение на Python для управления контактами. Проект разработан с упором на разделение логики по модулям и работу с постоянным хранилищем данных в формате JSON.

## Возможности

* ➕ Добавление новых контактов
* 📋 Просмотр всех контактов
* 🔍 Поиск контактов по имени, телефону и email
* ❌ Удаление контактов по ID
* 📂 Просмотр списка избранных контактов
* ✏️ Редактирование информации о контакте
* 🔃 Сортировка контактов
* 💾 Автоматическое сохранение данных в `database/db_contacts.json`

## Используемые технологии

* Python 3
* JSON (модуль `json`)
* Модульная архитектура

## Запуск

```bash
git clone https://github.com/siriru08/Contact-Manager.git
cd Contact-Manager
python main.py
```

Дополнительные библиотеки не нужны.

## Структура проекта

```text
Contact-Manager/
│
├── main.py          # Главное меню
├── contacts.py      # Логика работы с контактами
├── storage.py       # Загрузка и сохранение данных
├── validators.py    # Проверка пользовательского ввода
└── database/
    └── db_contacts.json   # Хранилище контактов
```

## Формат данных

Каждый контакт в `database/db_contacts.json` — словарь:

```json
{
    "id": 1,
    "name": "Имя",
    "phone": "79991234567",
    "email": "mail@example.com",
    "address": "Город",
    "favorite": true
}
```

Старые записи (телефон числом, избранное строкой) автоматически приводятся к этому формату при загрузке.
